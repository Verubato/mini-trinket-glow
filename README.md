# MiniTrinketGlow

Simple addon that glows trinkets on your actions bars when they're off cooldown.

This makes it easier to see when your important PvP and other trinkets are available.

Features:

- Doesn't matter which action slot your pvp trinket is in.
- Combat only toggle option.
- Supports "/use 13" and "/use 14" macros.

Feedback and feature requests are more than welcome!
